
## Projekt felépítése

* **JDBC_connection** – JDBC-alapú adatbázis-kapcsolatok létrehozása és kezelése Databricks környezhez.
* **connect_to_PostgreDB_in_databricks** – PostgreSQL adatbázis csatlakoztatása Databrickshez, adatok beolvasása és lekérdezése két módszerrel:
  - JDBC segítségével
  - Data Ingestion
